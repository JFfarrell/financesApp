# Architecture - UI Layer

Jetpack Compose screens and components. Screens observe StateFlow from ViewModels and emit events back.

```mermaid
graph TD

    subgraph Navigation["Navigation"]
        NG["NavGraph"]
        NG ~~~ BNB["BottomNavBar"]
    end

    subgraph Screens["Screens"]
        DS["DashboardScreen"]
        DS ~~~ MS["MonthlyScreen"]
        MS ~~~ SS["SavingsScreen"]
        SS ~~~ LS["LoginScreen"]
    end

    subgraph Sheets["Bottom Sheets"]
        ATS["AddTransactionBottomSheet"]
    end

    subgraph Components["Shared Components"]
        TLI["TransactionListItem"]
        TLI ~~~ MS2["MonthSelector"]
        MS2 ~~~ CPA["CircularProgressArc"]
    end

    subgraph ViewModels["ViewModels"]
        DVM["DashboardViewModel"]
        DVM ~~~ CVM["CalendarViewModel"]
        CVM ~~~ SVM["SavingsViewModel"]
        SVM ~~~ LVM["LoginViewModel"]
    end

    BNB --> NG
    NG --> DS
    NG --> MS
    NG --> SS
    NG --> LS

    DS --> DVM
    MS --> CVM
    SS --> SVM
    LS --> LVM

    MS --> ATS
    ATS --> CVM

    DS ~~~ TLI
```

## Notes

- `MonthlyScreen.kt` contains `CalendarScreen`, and its ViewModel is `CalendarViewModel` (in `MonthlyViewModel.kt`).
- `AddTransactionBottomSheet` handles all three transaction types. It does not yet expose merchant or tag inputs (see backlog).
